# Changelog

All notable changes to Boars Book. The text of this file goes into each release's notes.

## 1.0.0 — 2026-10-22

First release.

- Dur Blackbeard's book: 14 chapters and 15 sketches on parchment, two pages side by side (a single page in a narrow
  window), page turn and book sounds, the reading place remembered.
- Boar hunt: targeting any of the 35 boars from the book records it (account-wide) with an achievement on parchment
  and a seal next to its name in the book showing when and where it was found.
- Finds: every boar by region, region achievements and Dur's complete bestiary; the Finds button glows while
  something is new.
- Page windows over the book: as many as you like, each turning its own pages.
- English and Russian; the language follows the game client and can be switched for the session.
- Minimap icon: left click opens the book, right click a page window.
